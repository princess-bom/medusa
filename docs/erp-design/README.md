# 아이엠 ERP 설계

[추측] Medusa의 판매·재고 기능을 재사용하고, 도매 업무를 별도 모듈로 확장하는 안을 제안한다. 레거시 ERP는 읽기 전용 연결부터 시작한다. 에이전트는 제안만 한다. 사람 승인 후에만 기록하고 실행한다.

[추측] 회계, 세무, 전자세금계산서는 이번 범위에서 제외한다. 미래 회계 서비스와 주고받을 업무 자료의 경계만 정한다.

## 표시와 조사 기준

[추측] `[확인한 사실]` 링크는 읽은 Medusa 소스 또는 공식 문서의 근거를 뜻한다. 실행 성공을 뜻하지 않는다. `[추측]`은 제안, 추론, 미확인 사항을 뜻한다. 표의 표시가 한 행 전체에 적용된다. 도식과 경로 목록은 바로 앞 문장의 표시를 따른다.

[추측] 조사 기준일은 2026-10-17이다. 로컬 Medusa 기준 커밋은 `906433ac6b1d5ec3cc23f88c8297d29fa87427fd`이다. `develop` 링크는 이후 바뀔 수 있으므로 재검토 때 기준 커밋과 대조한다.

[확인한 사실](https://github.com/medusajs/medusa/blob/develop/packages/medusa/package.json) 확인한 Medusa 패키지 버전은 `2.21.2`이다.

[추측] The_IM은 `gh repo clone`으로 `/tmp`에 받은 별도 저장소를 읽었다. 기준 커밋은 `5015d461b0c62f32c38456481dca547419341a8d`이다. 지정된 Medusa 근거 URL로 증명할 수 없는 The_IM 내용은 `[추측]`을 붙인 재사용 설계로 적었다. 읽은 원본 파일 경로와 상태 이름은 [승인 원칙](05-agent-api-principles.md)에 남겼다. 운영 서버의 동작은 확인하지 않았다.

## 조사와 문서 검증 범위

[추측] 소스 경로는 `ls`와 `rg --files`로 대조한다. 기능 판단은 모델·workflow·관련 테스트의 내용으로 대조한다. 테스트 파일을 읽은 사실과 테스트를 실행한 사실은 구분한다.

[추측] Enterprise 조사는 `ENTERPRISE-LICENSE.md`의 경로 목록, 패키지별 LICENSE, Enterprise 문구, `ee` 경로를 대조한다. [기능 문서](01-medusa-capabilities.md)에 제외 목록을 둔다. 외부 B2B starter와 외부 플러그인의 코드·라이선스는 이번 조사에서 검증하지 않았다.

[추측] 제출 전에는 일곱 Markdown 파일, 근거 링크의 로컬 경로, 상대 링크, Enterprise 제외 목록, Git 변경 범위를 검사한다. 앱 설치·DB 변경·운영 연결은 이 문서 작업의 검증에 포함하지 않는다.
